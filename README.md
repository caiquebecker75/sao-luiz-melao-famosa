# São Luiz × Melão Famosa — Estratégia de Trade Exclusiva

Apresentação HTML (deck de 12 telas) desenvolvida pela **75 LAB** para o time de varejo do
**Super Mercadinhos São Luiz**, propondo um piloto exclusivo de trade marketing para o **Melão Famosa** em 5 lojas.

🔗 **Link público:** https://projetos.75lab.com.br/sao-luiz-melao-famosa/

## Estrutura do deck

| # | Tela | Conteúdo |

## Como navegar

- **Rolar** a página, ou usar **↑ ↓ ← →**, **Page Up/Down**, **Espaço**, **Home** e **End**
- Os **pontos à direita** levam direto a qualquer tela
- Para gerar PDF: `Cmd/Ctrl + P` → salvar como PDF (layout paisagem)

## Identidade visual

Sistema próprio construído sobre a marca **Melão Famosa**: alternância entre telas
**tinta** (azul-marinho `#0B2340`) e **papel** (creme `#F3EEE2`), blocos sólidos de canto
generoso, fotos em moldura de arco, palavra-chave destacada em pílula verde e formas
orgânicas de fundo. Paleta: verde `#8CC63F`, dourado `#E9A93C`, terracota `#C2562B`.
Tipografia: **Bricolage Grotesque** (títulos) + **Archivo** (texto).

## Stack

HTML + CSS + JavaScript puro, arquivo único. Ícones em SVG inline com animações em loop.
Sem dependências externas além das fontes do Google Fonts.
